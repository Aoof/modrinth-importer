Modrinth Importer

Move your mods and modpacks to Modrinth.

A desktop app and command-line tool. Point it at a pack from another launcher and get a ready-to-use .mrpack, or publish your own mods to Modrinth.

Install

macOS and Linux

curl -fsSL https://raw.githubusercontent.com/Aoof/modrinth-importer/master/install/install.sh | sh

Windows (PowerShell)

irm https://raw.githubusercontent.com/Aoof/modrinth-importer/master/install/install.ps1 | iex

Installs the mrimport command and the desktop app, checksum-verified. Or download directly from Releases.

Use

mrimport convert MyPack.zip --open

Mods are matched to Modrinth by file hash first, then by name. Anything Modrinth doesn't host can be bundled into the pack, and you get a report of what was skipped.

Reads

  • CurseForge modpack zip, app instance
  • Prism Launcher / MultiMC instance folder or zip
  • ATLauncher instance folder
  • FTB App, Technic instance folder
  • packwiz pack folder or zip
  • Any mods folder folder of jars

Publishes from

  • Local jars
  • GitHub releases
  • CurseForge projects you own

New projects are created as drafts; already-uploaded versions are skipped.
